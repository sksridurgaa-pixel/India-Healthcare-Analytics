# 🇮🇳 India Healthcare Analytics

## 📊 Project Overview

An end-to-end healthcare analytics project analyzing patient
demographics, diseases, health metrics, treatment outcomes,
insurance coverage and hospital intelligence in India.

## 🛠️ Tools Used

- Excel
- SQL / MySQL
- Power BI
- DAX

## 📁 Project Structure

- PowerBI – Power BI dashboard
- SQL – SQL analysis queries
- Excel – Pivot tables and analysis
- Data – Source datasets
- Dashboard – Dashboard screenshots

## 📌 Key Analysis

- Patient demographics
- Disease burden
- Health metrics
- Treatment effectiveness
- Treatment outcomes
- Insurance coverage
- Hospital ratings
- Hospital density
- Regional healthcare analysis
